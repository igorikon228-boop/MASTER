# MASTER

MASTER — мобильное web-приложение для самостоятельных тренировок.

## Первая версия

- Раздел «Тренировка»
- Конструктор тренировки из блоков упражнений
- Изменение порядка упражнений drag-and-drop
- Настройка повторений/времени, подходов и отдыха
- Сохранение собственных тренировок
- Режим активной тренировки с таймером
- Раздел «Профиль»
- Имя, рост и вес
- Общая статистика тренировок, повторений и времени
- Статистика повторений по упражнениям
- Локальное хранение данных в браузере
- PWA manifest и service worker для запуска как web-app

## Запуск локально

Откройте проект через любой статический HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Публикация

Проект полностью статический и подходит для GitHub Pages.
